Přihlášení

Novinky se ukládají do repozitáře webu na GitHubu. Pro uložení potřebujete přístupový token.

Jak získat token
  1. Na GitHubu otevřete Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Resource owner: liberland. Repository access: Only select repositories → liberland/site.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Vytvořte token a vložte ho sem. Uloží se jen v tomto prohlížeči a nikam jinam se neposílá.

Váš GitHub účet musí mít do repozitáře liberland/site právo zápisu. Pokud organizace tokeny schvaluje, počkejte na schválení.
