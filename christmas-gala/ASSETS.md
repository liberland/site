None of these photographs is retouched. The Christmas decorations in the `christmas-lobby` image are the
hotel's own. The garlands and baubles drawn over the hero are page decoration, placed around the
photograph rather than edited into it.

To publish a photograph, save the approved file as `public/images/venue/<id>.webp` (about 2000 px
wide) and `<id>-800.webp`, then set `cleared: true` for it. Use the hotel's own credit wording if it
asks for one.
